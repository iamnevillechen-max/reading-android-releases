# 综合小说新增书源

书源文件：`tools/source-packs/verified-fiction.json`。

本轮选择官方纵横中文网，支持网页公开搜索、书籍详情及公开免费章节。覆盖平台的综合小说搜索，不把古籍包当成现代小说覆盖。

核验样本为《不让江山》，作者知白。普通 HTTPS 请求已完成搜索、详情、目录及第一章正文检查；正文只保存长度与 SHA-256，不放入书源包或公开报告。App 原生解析结果以 `fiction-source-verification.json` 及主任务本轮原生测试证据为准。

目录明确排除站点标为 VIP 的条目。样本原目录 1,565 项，其中 83 项未标 VIP，1,482 项不进入本规则目录；免费目录包含「新书感言」「楔子」和「上架感言」，不伪造为全部正文。第一章测试应按标题「第一章 凡事皆有度」选择，而非假设它是目录第零项。

正文规则只接受网页公开的 `data-prescription=0` 且 `data-decoder` 为空的节点；没有解密或付费接口。没有请求付费章节正文，没有登录或账户信息。发现分类暂未启用，不放未经核对的分类入口；这份新增源先提供可靠搜索与免费分章阅读。

搜索 JSON 地址来自官方搜索页自身公开脚本调用，不是 App 私有接口：

- [官方搜索页](https://search.zongheng.com/s?keyword=%E4%B8%8D%E8%AE%A9%E6%B1%9F%E5%B1%B1)
- [官方作品详情](https://www.zongheng.com/detail/966275)
- [官方章节目录](https://book.zongheng.com/showchapter/966275.html)
- [已核验的官方免费第一章](https://read.zongheng.com/chapter/966275/61162001.html)

导入时先核对同一来源网址的既有规则，保留原规则及阅读资料。书源包仅有解析规则，不附小说正文；网站内容及免费范围日后变化时须重新核对。
