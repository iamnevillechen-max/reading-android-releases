# 新增古籍书源

书源规则：`tools/source-packs/verified-classics.json`。包内不包含小说正文。

这轮先补充两项正常网页来源，范围是古典小说及公开古籍。没有把它们描述为现代连载小说书库。

| 来源 | 当前验证范围 | 使用范围 |
| --- | --- | --- |
| 维基文库·中文分章古籍 | 《西遊記》搜索、作者、100回目录及第一回原文；保留诗词列表 | 在线分章阅读；目录只收同一本书的「第…回／章／卷／節」链接 |
| 古文岛·公开小说目录 | 公开小说目录本机筛选《红楼梦》、作者、120回目录及第一回原文 | 在线分章阅读；按公开目录分页，不使用需要登录的站内搜索；未匹配不代表全站没有 |

普通 HTTPS 获取的搜索／目录页、详情页和正文页已核对。App 内实际解析验证以 `source-pack-verification.json` 及本轮 Android 原生测试结果为准；没有通过原生验证前，不把网页可达写成已能在 App 使用。

可从阅读的书源管理导入 JSON。导入前核对同一来源网址的既有规则；保留用户原规则和资料，避免未核对就覆盖。硬件连接和新书源的实际手机导入由主任务完成。

维基文库搜索页没有稳定的结构化作者，规则保持空白，详情页读取真实作者；不填虚构作者强行触发拼接。自动拼接仍须通过同书、同作者、同章和正文重叠的核对，来源数量增加不代表每本书都应拼接。

没有纳入本包的候选：Project Gutenberg 的《西遊記》网页是一个全文文件，没有分章锚点，不能冒充通用在线分章来源；它的 TXT 下载可以另做文件下载来源。Chinese Text Project 普通访问返回403，本轮没有尝试绕过。
