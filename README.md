# reading-android-releases
阅读 Android 安装更新与对应 GPL 源码

## 阅读项目反馈

可以请 ChatGPT Dot 代你提交遇到的问题。说明当时的操作和看到或听到的现象即可。若已在 Android 的「我的 → 上传使用日志」取得回执，可一并填写，方便维护者核对。反馈提交后会得到收件回执。[填写反馈](https://reading-feedback.iamnevillechen.workers.dev/) · [Dot 提交说明](https://reading-feedback.iamnevillechen.workers.dev/dot.json)

## 云端开发

在 Codex 云端继续「阅读开发」时，选择开发分支 `android-source`。Android 应用在 `upstream/`，反馈服务在 `server/feedback/`。[打开开发源码](https://github.com/iamnevillechen-max/reading-android-releases/tree/android-source)
